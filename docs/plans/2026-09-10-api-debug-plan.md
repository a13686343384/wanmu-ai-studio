## 现状盘点（执行前侦察结论）

- **#8 根因已明**：live 模式 `loadCustomModel(input.model)` 按 id 精确查找，批量出图按钮未传 model → 后端默认 `man-image-v2-lite` → 查无。修法 = live 下 model id 查不到时回退「该 kind 的启用 CustomModel」（优先第一个 enabled），mock 不受影响。
- **#7 待查**：提取路由 `POST /api/scripts/[id]/assets` 是否生成 costume 记录待查（推测：只提取 characters/scenes/props，从不生成妆造）→ 需在提取时为每个角色生成默认造型，或补缺漏时补造。
- **#3/#9/#10/#11**：现状「下一步·出人物/场景资产」= AssetSetupDialog 选模型后一次性提取+出图（ScriptDetailView.runNextStep），需拆分；进度条 runNextStep/WORKFLOW_STAGES 已有，需按规则推进；分镜区已有拆分 loading（需核对原型细节）；镜组分段概念当前不存在（storyboard 为扁平列表）→ 需新增 segment 概念（Storyboard 加 group 字段或前端按规则分组）。
- **#11 出片前检查已存在**（E2E 有覆盖），需按原型扩展：必须解决/建议补齐/相邻衔接建议三类 + 跳转动作。
- **#13 引用**：storyboard.generationParams 现无引用结构 → 新增 refs 字段（sceneId/characterId+costumeId/propIds），默认按分镜描述自动匹配。
- **#14**：分镜 videoUrl 为空时显示「生成视频」占位框，宽高比用 script.targetAspect。
- **#5**：角色/道具/场景三种「参考图提示词模板」写入 `buildAssetPrompt`（或独立模板），要求出图模型输出 image1/2/3 的卡面构图；配资产参考图弹窗的默认提示词。
