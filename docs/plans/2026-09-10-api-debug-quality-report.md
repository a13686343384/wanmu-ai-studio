## 二、详细执行计划（应然版——按需求正确拆解）

### Phase-1 止血与 Bug（0.5 天）
1. live 图片模型按 kind 回退；错误文案指引 /ai-settings
2. 提取路由事务后为无造型角色补默认造型
3. 资产四类卡放大镜 + 全屏预览
4. 提取请求携带 imageModel，注入提示词适配说明

### Phase-2 流程重构（1 天）
5. AssetSetupDialog 仅提取（移除出图相关死控件）；文案标明两步
6. 右栏「重新出图」= 四类逐类全量重出（空类别跳过）
7. 提取成功后 script.status → assets（进度规则的前置数据条件）

### Phase-3 进度与拆分镜（1.5 天）
8. WorkflowTabs：assetsReady 驱动进度显示（未出齐停大纲/出齐进拆分镜）
9. 拆分启动即收起弹窗；分镜区居中「AI 正在拆分镜…」+ 顶部「分镜 ■停止」
10. 完成 toast「整剧拆分镜完成 (N 集)」；分镜提示词时间轴 strip

### Phase-4 分镜完成页与段级弹窗（2.5 天）
11. 镜组分段渲染（segmentTitle 分组 + 段头状态 chips：拆分镜未生成/全镜组出图/全镜组生产中 + 建议 chips）
12. 出片前检查重排：必须解决（红+动作）/建议补齐（橙+去补首帧图）/相邻衔接建议（优先级 chips：视频延长/首帧图+调度图/只首帧图）
13. 段资产弹窗：真实模型选择、补全所有、重新生成全部、逐张/并发开关、安全改写透传、首帧图/调度图/人群调度卡真实生成
14. 编辑整段引用弹窗：自动匹配默认 + 场景/人物造型/道具选择 + 按条写入 refs + 「用于 N 集」跨集标注

### Phase-5 视频阶段（1 天）
15. 卡片占位框按画幅动态；video 阶段卡片不显示图片只显示「生成视频」占位；右上角批量生成视频

### Phase-6 内容质量（1 天）
16. 三类卡面提示词模板按 image1/2/3 重写
17. **用真实出图模型实测三类卡面效果，不达标迭代提示词直到符合**
18. 全局 loading 审计（全量 grep，非抽查）

### Phase-7 回归与验收（0.5 天）
19. tsc/build/smoke/E2E 全绿 + 逐条对照原型截图复查

## 五、根因分析（为什么质量不好）

1. **验收标准错位**：以「功能点了」为完成标准，没有回到原型图逐像素复查（需求 016 原文："这里要严格执行"被弱化为"结构差不多"）。
2. **审计不彻底**：需求 1 的全量 grep 只改了 grep 到的第一处就宣布完成——实际还有 4 处同模式假进度。
3. **验证环节被环境跳过且未声明**：需求 5 明确要求实测出图，因 ComfyUI 关机 + 无线上图模型直接跳过，且未在交付时主动声明该验证缺失。
4. **半吊子实现**：refs/安全改写/逐张出——状态存了或开关画了，但没有下游消费或行为差异，属于"看起来完成了"。
5. **上下文截断事故**：长会话中断导致个别补丁丢失（`__all__` 挂载丢失致批量生成弹窗打不开），虽已修复，但暴露了纯脚本补丁的脆弱性。
