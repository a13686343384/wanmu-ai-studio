# 参考图查缺补漏与画布修复

## 交付范围
1. 全图对照清单：按业务能力记录已有、缺失、此次修复与仍需后端服务的边界。
2. 优先修复画布：固定边缘连接点，取消鼠标位置驱动变换；统一 MiniMap 的 SVG/外框尺寸；工具栏留独立空间，窄屏可换行；加载失败不自动覆盖；保存串行化，保留未保存状态；拖动/删除/连接撤销正确；右键上传保留落点并持久化；生成参数可编辑与保存；节点侧栏可恢复。
3. 剧本创作：独立项目列表与配置弹窗；编剧工作区、蓝图/角色/分集/正文/历史；AI 接口走服务抽象层；工作区权限与数据库持久化；正文编辑/下载和导入影视工厂。默认 Mock，使用真实数据库保存结果。
4. 影视工厂：记录参考图差距，优先补齐下一步资产配置与分镜出片检查入口。涉及真实模型、对象存储、后台任务及视频编码的能力如实记录，不以成功提示替代产物。

## 实现原则
保留 Next14/React18/Tailwind3/Prisma6。以 zinc 深色和 orange-500 为品牌色；复用弹窗、按钮、模型清单。画布实时状态保持 React Flow，创作项目新增独立数据模型，避免混进影视工厂列表。保存采用版本检查防止覆盖他人/旧请求结果。小地图和底栏始终可点击，输入框的操作不得触发节点拖动或删除。
